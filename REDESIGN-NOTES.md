# CONCEPT GRID Website Redesign

## Direction
An architectural editorial system designed to feel considered, precise, and premium. It preserves the existing project photography and contact destinations while giving the work more space and a stronger narrative.

## Design tokens
- Graphite: #171916
- Secondary graphite: #242720
- Warm paper: #F5F3ED
- Concrete surface: #EBE9E1
- Accent yellow: #E5C21B
- Muted text: #696C64
- Divider: #D7D5CB
- Display type: Manrope ExtraBold / Bold
- Body type: DM Sans Regular / Medium / Bold

## Homepage story
1. Utility strip and editorial navigation
2. Hero: “Architecture, made tangible.”
3. Service ticker
4. Six capabilities in a considered grid
5. Studio approach and positioning
6. Selected work using the existing eight portfolio images
7. Three-step project process
8. High-contrast contact conversion section
9. Footer with portfolio and contact destinations

## Implementation notes
- Single-file static HTML/CSS/JS, no framework or build dependency added.
- Responsive desktop, tablet, and mobile layouts.
- Accessible language toggle with English and Arabic copy and direction switching.
- Mobile navigation with expanded-state attributes.
- Preserves the existing local logo and project asset paths.
- Uses direct WhatsApp, email, telephone, and Behance links.
- Includes reduced-motion support, keyboard focus styling, alt text, lazy-loaded project images, and metadata for social previews.

## Review checklist
- Check all eight project images after deployment.
- Verify Arabic and English layouts at desktop and mobile widths.
- Test WhatsApp, telephone, email, and Behance destinations.
- Confirm GitHub Pages Actions completes before considering the change live.
